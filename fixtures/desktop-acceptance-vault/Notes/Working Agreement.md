# Working Agreement

The launch group keeps decisions close to the evidence that informed them. A
task is not considered ready merely because it is listed; it needs an owner, a
project, and a due date when timing matters. When a task is intentionally
abandoned, the note should say so rather than letting the work silently age.

We use the Tuesday review to make risks visible, the Thursday review to confirm
release readiness, and the decision log to record trade-offs. This prevents a
short-lived chat discussion from becoming the only explanation of a meaningful
product choice.
