# Partner Enablement

Implementation partners will be invited after the internal pilot has shown that
the guided setup works without a live walkthrough. The partner kit should give
them enough context to explain the workflow accurately while avoiding promises
about features outside the first release.

## Handoff package

- A short narrative based on [[Product/Northstar Brief]].
- A verified set of launch conditions from [[Decisions/ADR-004-Launch-window]].
- The support escalation route from [[Work/Launch Readiness]].
- A migration checklist from [[Guides/Partner Migration Checklist]].

## Facilitation notes

Partners should start with the customer problem, not a feature tour. A useful
opening question is: "Which person is accountable for deciding whether this
initial configuration is safe enough to share?" That question reveals whether
the recommended template needs additional explanation.

## Review

The enablement lead will run one dry session with a partner manager before the
pilot cohort expands. Notes from that session belong in the launch decision log.
