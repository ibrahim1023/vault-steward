# Northstar Launch Workspace

This is a realistic manual acceptance vault for Vault Steward. It represents a
small product team preparing a customer-facing launch for a workflow called
Northstar. The material is intentionally substantial enough to exercise vault
navigation, meaningful evidence locators, local-model context, and a broad
range of deterministic integrity checks.

Some documents deliberately contain defects. Do not use this folder as a
template for a production vault.

## Intended defects

- `Projects/Northstar Launch.md` has no project owner.
- `Decisions/ADR-004-Launch-window.md` has no rationale.
- `Work/Launch Readiness.md` contains an overdue, orphaned, duplicate,
  abandoned, and malformed task.
- `Work/Partner Enablement.md` contains one repairable broken wiki link.
- `Research/Customer Interviews.md` contains a broken anchor and a missing
  embedded note.
- `Notes/Working Agreement.md` contains an unsupported external-style target.
- `People/Elena Markova.md` and `People/Elena M.md` describe an intentional
  duplicate entity; `Work/Partner Contact Review.md` supplies wiki, embed, and
  Markdown inbound references for the Phase 25 manual consolidation pass.

Keep a pristine copy. Several test cases modify or rename the supplied files.
