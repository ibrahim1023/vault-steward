# Atlas Release

Atlas is a staged release of workspace automation for regional operations
teams. The release replaces manual role setup with an auditable import and
review workflow. The initial cohort is limited to twelve customer workspaces.

## Outcome

Administrators should complete their first import in less than twenty minutes
without a support-led configuration session. Success depends on validated
permission mappings, clear escalation ownership, and a reproducible handoff.
