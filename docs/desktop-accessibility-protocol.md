# Desktop Accessibility Protocol

Run this in each supported Obsidian desktop release line before distribution: open Vault Steward from the ribbon and command palette; navigate every control by keyboard; confirm focus remains visible; run a scan; inspect a finding, Policy Studio, model readiness, maintenance controls, and history; test the narrow sidebar; verify error alerts are announced once; then disable/re-enable the plugin and repeat.

Record the Obsidian version, operating system, vault fixture revision, local model state, and any failed step. Automated UI tests do not replace this protocol.
